# Security

WealthScale is a browser application. It validates third-party wealth estimates
before rendering them. Personal reference amounts stay in page memory, while
image exports may contain the displayed reference. Avoid including personal
amounts or sensitive browser data in bug reports.

Use [GitHub private vulnerability reporting](https://github.com/MediaChronicle/WealthScale/security/advisories/new)
for security vulnerabilities. The repository setting was enabled and verified on
13 October 2026. If the form is unavailable, do not put exploit details,
credentials or personal information in a public issue or PR.

Report ordinary, non-sensitive rendering and data bugs through GitHub issues.
Dependency audit results apply to the tested revision and audit database at the
time of the check. Automated checks do not establish real-device graphics or
touch behavior.
